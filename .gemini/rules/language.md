# Global Project Standards: English Only

## Rule Definition
All project source code, documentation, tests, templates, CLI output, error messages, identifiers, and configuration MUST be written strictly in **English**.

### Specific Guidelines:
1. **Source Code & Comments:** All code, comments, JSDoc, interfaces, class names, functions, variables, and constants must be in English.
2. **CLI Outputs & Errors:** Terminal messages, command descriptions, logs, error messages, and banners must be in English.
3. **Templates & Scaffolding:** All scaffolded code (`make:*`, `new`, etc.) and views must use English placeholder content and labels.
4. **Documentation:** `README.md`, guides, API references, and architecture docs must be in English.
5. **Tests:** All test suite descriptions and assertion messages must be in English.
