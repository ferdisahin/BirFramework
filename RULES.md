# Project Rules & Standards

## 1. Language Standard (Global First)
- All codebase elements, including comments, commit messages, documentation, error messages, and CLI outputs, must strictly be in **English**.
- No Turkish or non-English text in code, scaffolding templates, or test suites.

## 2. Code Quality & Ergonomics
- Strict TypeScript (`strict: true`) with full zero-magic type inference.
- Dual-runtime support (Node.js 22+ & Bun).
- Dual-language scaffolding: support both TypeScript (`--ts`) and JavaScript (`--js`).
- Laravel Developer Experience (DX): fluent, expressive, readable API.
